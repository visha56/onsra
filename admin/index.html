🔑 GitHub Personal Access Token

थेट मोबाईल किंवा इतर कोणत्याही ब्राउझरवरून लाईव्ह वेबसाइटवर बदल सेव्ह करण्यासाठी एका मिनिटांत GitHub टोकन तयार करून येथे सेव्ह करा.

टोकन कसे मिळवायचे (फक्त १ मिनिटांत):
१. GitHub.com ला लॉगिन करा आणि Settings > Developer settings > Personal access tokens > Tokens (classic) वर जा.
२. Generate new token (classic) निवडा.
३. फक्त repo या पर्यायावर टिक (check) करा आणि Generate token बटण दाबा.
४. आलेले टोकन कॉपी करून वरील बॉक्समध्ये पेस्ट करा. हे टोकन तुमच्याच फोन/ब्राउझरमध्ये सुरक्षित सेव्ह राहील.
