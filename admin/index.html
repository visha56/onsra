'Your Home for 24 Days' समोरील सध्याचा मुख्य फोटो प्रीव्ह्यू.
🛏 खोल्यांचे प्रकार आणि फोटो (Accommodation Rooms)

Accommodation पेजवरील खोल्यांची नावे, फोटो, वर्णन आणि सुविधा (Amenities) बदला.

होमपेजवरील टेस्टीमोनियल स्लाइडरमधील रिव्ह्यूज व्यवस्थापित करा.

तुमच्या कॉम्प्युटर किंवा मोबाईलवरून नवीन फोटो अपलोड करा. तो थेट वेबसाईटच्या images/ फोल्डरमध्ये सेव्ह होईल.

येथे फोटो निवडा किंवा ड्रॅग करा

JPG, PNG किंवा WebP फॉरमॅट सपोर्टेड (हाय-क्वालिटी ऑटो-ऑप्टिमायझेशन)

खालील कोणत्याही फोटोची लिंक एका क्लिकवर कॉपी करू शकता किंवा नको असलेला फोटो डिलीट करू शकता.

🧘 तत्त्वज्ञान व आश्रम परिचय (Philosophy & Story)

होमपेजवरील 'Rooted in Tradition, Open to the World' मधील सुविचार व परिचय मजकूर बदला.

🌿 अबाउट पेज आश्रम फोटो (About Us Ashram Photo)

🔑 GitHub Personal Access Token

थेट मोबाईल किंवा इतर कोणत्याही ब्राउझरवरून लाईव्ह वेबसाइटवर बदल सेव्ह करण्यासाठी एका मिनिटांत GitHub टोकन तयार करून येथे सेव्ह करा.

टोकन कसे मिळवायचे (फक्त १ मिनिटांत):
१. GitHub.com ला लॉगिन करा आणि Settings > Developer settings > Personal access tokens > Tokens (classic) वर जा.
२. Generate new token (classic) निवडा.
३. फक्त repo या पर्यायावर टिक (check) करा आणि Generate token बटण दाबा.
४. आलेले टोकन कॉपी करून वरील बॉक्समध्ये पेस्ट करा. हे टोकन तुमच्याच फोन/ब्राउझरमध्ये सुरक्षित सेव्ह राहील.
